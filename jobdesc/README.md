# Dokumentasi Job Description IMNEHNET

Dokumentasi Progress 2 semester 5 dikelompokkan berdasarkan PIC, dengan struktur direktori yang konsisten. Folder `jobdesc/` menyimpan **bukti dan penjelasan**; source produksi OpenTofu, Ansible, dan Laravel tetap pada direktori kanoniknya.

| PIC | Peran | Dokumentasi |
| --- | --- | --- |
| Alief | DevOps | [DevOps](DevOps/) |
| Ridho | Security Engineer | [Security-Engineer](Security-Engineer/) |
| Abdi | Cloud Architect | [Cloud-Architect](Cloud-Architect/) |
| Malik | Portal Developer | [Portal-Developer](Portal-Developer/) — progres individu belum diserahkan |

Setiap folder berisi:

- `scripts/`: dokumentasi script, perintah, dan tautan ke source asli (bukan salinan runtime).
- `notes/`: catatan, laporan langkah kerja, dan dokumentasi teknis.
- `pengujian/`: metode, hasil, keterbatasan, dan bukti pengujian.
- `images/`: screenshot atau daftar bukti visual.

> Perpindahan dokumen tidak berarti pengujian atau deployment baru dilaksanakan. Klaim tetap mengikuti bukti yang ada. Untuk laporan audit bersama lihat [docs/audits](../docs/audits/).
