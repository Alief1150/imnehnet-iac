## TF FILES
1. tofu/version.tf
Fungsi: Untuk memanggil versi OpenTofu yang terinstal
Kategori: Dependency Management

2. tofu/provider.tf
Fungsi: Menghubuungkan OpenTofu dengan server Incus
Kategori: Infrastructure Connectivity

3. tofu/variables.tf
Fungsi: Mendefinisikan variabel-variabel yang digunakan dalam OpenTofu
Kategori: Input Configuration

4. tofu/main.tf
Fungsi: Mendefinisikan dan mengelola container
Kategori: Resource Provisioning

5. tofu/outputs.tf
Fungsi: Menghasilkan informasi container setelah provisioning
Kategori: Infrastructure Output
